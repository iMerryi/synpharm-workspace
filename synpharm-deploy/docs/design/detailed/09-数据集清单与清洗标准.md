# 数据集清单与清洗标准

> **文档版本**：v1.0
> **日期**：2026-10-27
> **状态**：清单基线，待评审
> **上游**：[靶点库数据仓库设计说明书](./08-靶点数据仓库设计说明书.md)、[数据层详细设计](./01-数据层详细设计.md)
> **用途**：回答两个问题——**需要哪些数据集**、**每个数据集清洗到什么程度**。清洗等级的定义与验收口径见 §2，逐数据集要求见 §4。

---

## 1. 使用方式

- **P0**：靶点仓库最小闭环，必须先接；**P1**：平台核心建模与评测；**P2**：按业务需求接入。
- 每个数据集给出**目标清洗等级**（C0~C5）。等级不是越高越好：**过度清洗会销毁证据、引入选择偏差**，因此同时给出“绝对不要做”的边界。
- 所有数据集必须先通过**许可与用途核验**（§6），未确认的数据只能下载到隔离区，不得进入正式发布层。
- 清洗结论以“可追溯、可复现、可回滚”为准，不以“数据变干净”为准。

---

## 2. 清洗等级定义

| 等级 | 名称 | 做什么 | 退出条件 |
|---|---|---|---|
| **C0** | 归档与校验 | 登记来源、版本、许可快照、文件 SHA-256；原始文件只读留存 | 文件可复验，版本与许可能追溯 |
| **C1** | 结构解析 | 解析原始格式（FASTA/mmCIF/JSON/TSV/SDF），逐记录落候选，解析失败逐条留错 | 解析成功率与失败清单可查，无静默丢弃 |
| **C2** | 字段规范化 | 单位、枚举、标识、序列、SMILES、日期的规则化；保留 raw 与 normalized 两份值 | 每条标准值都能回指原值，规则版本可查 |
| **C3** | 实体消歧与去重 | 跨记录/跨来源识别同一实体；歧义进入复核而非自动合并 | 唯一键生效，重复导入不新增，歧义有状态 |
| **C4** | 质量过滤与冲突标注 | 质量规则打分/标记，冲突显式保留；决定“能否发布” | 阻断项清零，警告项可查询，被排除记录仍可追溯 |
| **C5** | 基准切分与泄漏控制 | 按骨架/序列聚类/时间/官方划分隔离训练与评测；检查跨集重叠 | 切分哈希固定，重叠检查通过 |

**组合原则**

- 结构/序列类：至少 **C1+C2+C3**；用于建模或评测再叠加 **C4/C5**。
- 活性/亲和类：至少 **C1+C2+C3+C4**；用于训练/评测必须 **C5**。
- 基准数据集：**C5 是强制项**，且不得重新切分后与官方结果直接比较。
- 仅作参考的工具/服务：**C0**（登记即可），不冒充数据集。

## 4. 分环节清单与清洗要求

### 4.1 靶点与结构（P0）

#### 4.1.1 UniProt —— 靶点身份与序列的唯一锚点

| 项 | 要求 |
|---|---|
| 稳定键 | UniProt accession（主）+ 物种 taxon + entry version |
| 目标等级 | C0+C1+C2+C3；注释字段做 C2 证据化 |
| 必做清洗 | ① 只取指定 proteome/taxon 的 Swiss-Prot；TrEMBL 仅作补充并显式标 `unreviewed`；② accession 去空白、格式校验、记录 secondary accession 与合并历史；③ FASTA 去头/空白/行号，保留原始序列；④ 校验残基字符集（含 X/B/Z/U），长度取规范化序列，计算 SHA-256；⑤ isoform 独立记录，不拼进 canonical；⑥ taxon ID 与物种名并存；⑦ 推荐名/基因名/同义词拆分，别名入 `target_alias`；⑧ 功能、定位、疾病关联保留原文+来源记录 |
| 可选 | 序列特征（结构域、跨膜区）按需接入并标来源 |
| 绝对不要做 | 用基因名/名称匹配代替 accession；把 TrEMBL 与 reviewed 同权；删除 X/B/Z/U 或“修补”序列；用新 release 覆盖历史序列；把中文名当作 UniProt 字段（中文名须另标人工词典来源） |
| 验收 | 100% 序列可算 SHA-256 且长度一致；抽样 100 条与 FASTA 逐字一致；accession 唯一；重复导入新增 0 条 |

#### 4.1.2 PDB —— 实验结构

| 项 | 要求 |
|---|---|
| 稳定键 | PDB ID + entity/chain（**不是**单个 PDB ID） |
| 目标等级 | C0+C1+C2+C3；结构质量标记 C4 |
| 必做清洗 | ① mmCIF 优先，解析 entity/polymer/chain/assembly；一个 PDB 可对应多靶点多链，禁止压成 `target.pdb_ids` 一个字段；② 链→UniProt 优先用来源交叉引用，其次 100% 序列一致才自动映射，其余进复核；③ 记录方法（X_RAY/CRYO_EM/NMR）、分辨率（Å）、R-free、clashscore、Ramachandran、缺失残基、altloc 处理策略、共晶配体数；④ 结构文件 SHA-256 + 快照日期；⑤ 处理 insertion code、修饰残基、hetero 分离；⑥ 共晶配体与“口袋”分开建模 |
| 可选 | 生物组装、二级结构、溶剂可及性 |
| 绝对不要做 | 仅凭分辨率阈值物理删除低质量结构（应作为可筛选质量属性）；修改坐标或补残基后仍称“实验结构”；同一 PDB 多链只保留一条；把 AlphaFold 记录写成 PDB 来源 |
| 验收 | 100% 已发布结构有方法、文件摘要、映射状态；映射冲突可查；同 `(target_id, source, source_key)` 重复导入 0 新增 |

#### 4.1.3 AlphaFold DB —— 预测结构

| 项 | 要求 |
|---|---|
| 稳定键 | UniProt accession + 模型版本 |
| 目标等级 | C0+C1+C2 |
| 必做清洗 | ① `source=ALPHAFOLD`、`experiment_method=PREDICTED`；② 记录模型版本与生成批次；③ 保留 pLDDT（均值/逐残基），PAE 可选；④ 校验序列与所用 UniProt 版本一致，不一致必须标差异；⑤ 标记 isoform/fragment；⑥ 不设实验分辨率 |
| 绝对不要做 | 分辨率填 0；标成 X_RAY；把 pLDDT 当实验质量；与实验结构合并为一条；用预测结构替代缺失的实验结构而不提示用户 |
| 验收 | 预测结构 100% 带 PREDICTED 标识；序列摘要与 UniProt 对应或显式标差异；重复导入幂等 |

#### 4.1.4 Open Targets / PHAROS —— 可药性与疾病证据（P2）

- **目标等级**：C1+C2+C3。
- **必做**：靶点映射（Ensembl→UniProt）、疾病映射（EFO/MONDO）、保留 evidence type/score/datasource/文献；区分“关联证据”与“因果结论”；不同来源分数不直接相加，若聚合须有版本化归一方法。
- **禁止**：把 association score 当“可药性结论”；无来源合并；把不同疾病本体混为一类。
- **验收**：每条关联可回指来源与文献；`(target, disease, source)` 唯一。

### 4.2 化合物库

#### 4.2.1 ChEMBL —— 化合物-活性-靶点主数据（P1）

| 项 | 要求 |
|---|---|
| 稳定键 | molecule: ChEMBL ID + InChIKey；activity: activity_id；assay: assay_id |
| 目标等级 | C1+C2+C3+C4；建模/评测加 C5 |
| 必做清洗 | ① 保留原始 molfile/SMILES，另存 RDKit 规范化 canonical SMILES/InChI/InChIKey，RDKit 版本固定；② 盐/溶剂/电荷/立体化学处理规则版本化，母体归并但保留子记录；③ 活性保留 raw value、单位、关系符（`=`/`>`/`<`/`~`）、类型（IC50/Ki/Kd/EC50…）、assay_id；④ 仅对可线性换算单位统一到 nM，不能换算的保持原值并标记；⑤ pChEMBL 仅对可用值计算；⑥ assay confidence、assay type、target mapping 一并保留；⑦ 低置信靶点映射不进入 DTA 训练集；⑧ 同一测量多条记录**全部保留**，聚合视图另建并声明规则 |
| 可选 | 分子属性、专利/文献关联、靶点复合物组分 |
| 绝对不要做 | 只存 pChEMBL 丢掉原始值与关系符；把 IC50/Ki/Kd 混为一列不标类型；按“活性好/差”删记录（选择偏差）；跨来源取平均；用最新 release 改写历史结果 |
| 验收 | 每条活性可回溯 assay/document/来源；单位换算可审计；同 release 重跑结果集哈希一致；无效结构比例有报告 |

#### 4.2.2 PubChem —— 化合物与生物测定（P2）

- **目标等级**：C0+C2+C3。
- **必做**：区分 CID/SID/AID；按 CID 与 InChIKey 去重；保留 depositor；只按需抽取目标 assay；结构标准化与 ChEMBL 同一套规则；混合物/聚合物/无机物显式标记。
- **禁止**：全库直接入关系库；把 PubChem 计算属性当实验值；不同来源同名属性互相覆盖。
- **验收**：CID/InChIKey 唯一；每个属性带来源；抽取脚本可按 assay 列表复现。

#### 4.2.3 ZINC —— 虚拟筛选化合物库（P1）

- **目标等级**：C1+C2+C3。
- **必做**：区分 2D catalog 与 3D docking-ready；记录质子化/互变异构模型与 pH 假设；去盐；按 InChIKey 去重；保留 tranche/subset、供应商、可购买状态与抓取日期。
- **禁止**：把 3D 构象当唯一结构；把“可购买”当永久事实（必须带时间）；与 ChEMBL 活性记录按分子直接合并去重（用途不同）。
- **验收**：同子集可复现；SMILES↔3D 文件对应；供应商与日期可查。

#### 4.2.4 DrugBank —— 药物-靶点与 DDI（P2，许可受限）

- **目标等级**：C1+C2+C3（且仅在授权范围内）。
- **必做**：drug ID、批准状态（approved/investigational/withdrawn）、靶点关系、ATC、DDI；映射 ChEMBL/UniProt；区分药物与代谢物。
- **禁止**：未获商业授权入库或再分发；把自由文本 DDI 当结构化关系；把在研药物与上市药物混为一类。
- **验收**：许可快照与可见范围受控；每条关系可回溯 DrugBank 记录。

### 4.3 结合亲和力 / DTI / DTA

#### 4.3.1 BindingDB（P1）

| 项 | 要求 |
|---|---|
| 目标等级 | C1+C2+C3+C4；训练加 C5 |
| 必做清洗 | ① 单位统一到 nM（仅线性可换算）；② 保留原始关系符与亲和类型；③ 蛋白映射 UniProt，突变体单独标注（突变位点/类型）；④ 配体 RDKit 标准化并保留原始结构；⑤ 与 ChEMBL 交叉识别但**双来源并存**；⑥ 同一文献多测定全部保留；⑦ 无序列/无结构配体隔离而非删除 |
| 绝对不要做 | 静默丢弃冲突值；Kd/IC50/Ki 混训不标类型；跨来源取平均；按阈值删“弱活性” |
| 验收 | 每条有来源记录+原始单位；重复导入幂等；与 ChEMBL 重叠率有报告且可解释 |

#### 4.3.2 PDBbind / CASF（P1）

- **目标等级**：C1+C2+C3+C4+C5。
- **必做**：PDB ID + 配体链/残基定位；亲和类型与单位核实；共价/肽类/金属配位异常**标记**；结构质量（分辨率、缺失残基）标注；CASF core set 与训练集严格隔离。
- **禁止**：用 CASF 训练或调参；一个复合物多配体只留一个且不标注；预测结构与实验结构混用于评分。
- **验收**：按 PDB ID、配体 InChIKey、序列相似度三重检查无重叠；CASF 指标可复现。

#### 4.3.3 DUD-E（P1）

- **目标等级**：C1+C2+C3+C4+C5。
- **必做**：活性/decoy 标签；按靶点组织；decoy 物性匹配检查；与 ChEMBL 交叉剔除“其实是活性”的 decoy；去重；按靶点切分。
- **禁止**：用同靶点 decoy 训练再同靶点评测（泄漏）；把 decoy 当实验阴性数据；跨靶点混合后随机切分。
- **验收**：每靶点活性/decoy 数量与重叠检查报告；富集评测脚本固定。

#### 4.3.4 SAIR（P2）

- **目标等级**：C1+C2+C3+C4。
- **必做**：结构质量、配体身份、亲和单位、PDB 映射；按序列相似度聚类切分；共价/非天然配体标记。
- **禁止**：直接用默认切分跨数据集混用；忽略结构质量。
- **验收**：结构-配体-活性三元组一致率报告。

#### 4.3.5 PLINDER（P1）

- **目标等级**：C1+C2+C3+C5。
- **必做**：采用其质量/置信字段；结构-配体映射校验；使用其相似性聚类切分；与 PDB 版本对齐；与 PDBbind/ChEMBL 做重叠检查。
- **禁止**：忽略其提供的切分；混合训练不查重叠。
- **验收**：与 PDB 快照一致；切分泄漏检查通过。

#### 4.3.6 DTI 基准：Davis / KIBA / BioSNAP（P1）

- **目标等级**：C2+C3+C5。
- **必做**：药物 SMILES 标准化、蛋白序列规范化、亲和单位统一；按药物/蛋白冷启动切分；去重；记录原始论文口径。
- **禁止**：随机切分后声称冷启动性能；同一配体/蛋白跨训练测试；不同基准的指标直接横比。
- **验收**：切分报告区分 cold-drug/cold-protein/random；指标可复现。

### 4.4 ADMET / 毒性 / 成药性

#### 4.4.1 TDC ADMET（P1）

- **目标等级**：C1+C2+C3+C5（轻清洗、重切分）。
- **必做**：使用官方任务定义与官方 split；核对标签单位/阈值；SMILES 标准化；跨任务重复化合物检测；缺失标签保留为缺失。
- **禁止**：重新随机切分后与官方榜单比较；把不同端点合并成一个“ADMET 总分”；用测试集调参。
- **验收**：官方 split 哈希一致；重跑指标可复现；跨任务重叠报告。

#### 4.4.2 ToxRefDB / EPA CompTox（P2）

- **目标等级**：C1+C2+C3。
- **必做**：化学身份映射（DTXSID/CAS）；物种、剂量、暴露时长、端点归一；单位统一；重复实验保留；明确定义阳性/阴性。
- **禁止**：跨物种直接合并；把“未观察到效应”当“无毒性”；端点定义混用。
- **验收**：端点字典版本化；物种/剂量/时长可查。

#### 4.4.3 不接入项

| 对象 | 原因 | 处理 |
|---|---|---|
| ChemIDplus | 已停止维护 | 以 PubChem / EPA CompTox 替代，不新建接入 |
| SwissADME | 在线预测工具，非数据集 | 仅作对照参考，不入标准标签层 |
| ADMETlab | 同上 | 仅作对照参考，不入标准标签层 |

---

### 4.5 分子生成 / 反应 / 逆合成

#### 4.5.1 MOSES / GuacaMol（P1）

- **目标等级**：C1+C2+C3+C5。
- **必做**：SMILES 解析/规范化/去重；剔除无效、含金属、超大分子（规则版本化并保留剔除原因）；使用官方 split；训练集与测试集按骨架去重。
- **禁止**：测试集调参；只报 validity 不报 novelty/diversity；清洗后与原论文口径混比。
- **验收**：指标脚本固定版本；清洗前后数量与规则记录齐全。

#### 4.5.2 USPTO（P2）

- **目标等级**：C1+C2+C3+C5。
- **必做**：reaction SMILES 解析、原子映射校验、试剂/溶剂规范化、去重、按专利/时间切分、模板抽取版本化。
- **禁止**：随机切分（时间泄漏）；把失败反应当负样本且不标来源。
- **验收**：反应有效率、原子映射覆盖率、切分报告。

#### 4.5.3 GDB-13 / GDB-17（P2，仅子集）

- **目标等级**：C1+C2。
- **必做**：按规则抽取子集；canonical SMILES；价键/芳香性校验；去重。
- **禁止**：全量导入 GDB-17（千亿级枚举）；把枚举空间当“可合成/可购买”分子。
- **验收**：子集生成脚本带 seed/规则，可复现。

### 4.6 平台评测基准

| 数据集 | 目标等级 | 必做 | 禁止 | 验收 |
|---|---|---|---|---|
| **TDC（全量）** | C1~C3+C5 | 官方任务与 split；逐任务许可核验；跨任务去重 | 自定义切分冒充官方成绩 | 每任务可用、可复现、有数据版本 |
| **FoldBench** | C1~C5 | 官方输入/参照；预测结构单独存放并标 PREDICTED；检查与训练集重叠 | 用预测结构当参照真值；跨版本混比 | 逐目标结果与官方指标口径一致 |
| **COValid** | C1~C5 | 共价弹头/反应基团标注；共价键记录；官方划分；与共价训练集查重 | 忽略共价键生成普通对接样本 | 切分无重叠，评测脚本固定 |

## 5. 跨数据集统一规则

### 5.1 标识与映射

| 对象 | 主标识 | 辅助标识 | 规则 |
|---|---|---|---|
| 靶点 | UniProt accession | Ensembl gene、ChEMBL target | accession 变更保留映射历史；名称不作主键 |
| 蛋白结构 | PDB ID + entity/chain | 文件 SHA-256 | 同结构多链分别映射 |
| 化合物 | InChIKey | ChEMBL/PubChem CID、CAS | 以标准化结构计算，不以供应商 ID 为准 |
| 疾病 | EFO/MONDO | 来源原始词条 | 本体版本随 release 固定 |
| 反应 | reaction SMILES 哈希 | 专利/文献 ID | 原子映射单独校验 |

### 5.2 分子标准化流水线（统一一套，禁止各模块自行实现）

1. 保留原始结构（molfile/SMILES）不动。
2. 去盐、去溶剂、保留最大片段（规则版本化）。
3. 电荷/质子化按声明模型处理，结果单独字段保存。
4. 立体化学保留，未知立体不得臆造。
5. 输出 canonical SMILES、InChI、InChIKey（含骨架前 14 位）。
6. 无效结构进隔离区并记录原因，不静默丢弃。
7. 全流程固定 RDKit 版本，升级须重跑并出差异报告。

### 5.3 活性与亲和力规范

- 原始值、原始单位、关系符、测定类型四件套必须同时存在。
- 只对可线性换算的单位做 nM 归一；`>10000` 这类截断值保持截断语义，不当作精确值。
- 不跨来源取平均；聚合必须显式声明规则并保留贡献记录。
- IC50/Ki/Kd/EC50 不混为一列；训练集必须能按类型过滤。
- 同一实验多重复值全部保留，冲突标 `CONFLICT`。

### 5.4 切分与泄漏控制

- 分子任务：骨架切分（scaffold split）或官方 split；训练/验证/测试按 InChIKey 骨架查重。
- 蛋白任务：序列相似度聚类切分（如 30%/40% 阈值需声明）。
- 时间相关任务：按年份/专利时间切分。
- 跨数据集训练：必须做 PDB ID、配体、序列、骨架四类重叠检查，并输出报告。
- 切分文件与随机种子入库，指标必须绑定切分哈希。

### 5.5 版本与可复现

每个发布单元必须同时记录：`source` + `release` + 文件 SHA-256 + 解析器版本 + 清洗规则版本 + 切分版本。缺任一项，不得标记为可复现数据。

## 7. 分批接入 Checkpoint

### 7.1 P0 —— 靶点仓库最小闭环

- [ ] UniProt：指定 taxon 的 Swiss-Prot 全量 + 序列 SHA-256 校验。
- [ ] PDB：mmCIF 解析 + 链/entity 映射 + 结构质量字段。
- [ ] AlphaFold DB：按 UniProt accession 批量接入，标 PREDICTED。
- [ ] 来源/版本/批次/来源记录/序列版本/质量问题表落地。
- [ ] 重复导入 0 新增；冲突进复核；发布可回滚。
- [ ] 现有靶点查询、项目绑定、基线冻结 E2E 通过。

**DoD**：任一已发布靶点能回答“来自哪个 release、哪条来源记录、哪个批次、用的什么规则、序列摘要是什么”。

### 7.2 P1 —— 建模与评测主链路

- [ ] ChEMBL：先接指定靶点/适应症子集，再评估全量。
- [ ] BindingDB：与 ChEMBL 双来源并存，重叠率报告。
- [ ] ZINC：按项目需要的 tranche 接入，不接全量 3D。
- [ ] TDC ADMET：官方 split，指标可复现。
- [ ] PDBbind/CASF、DUD-E、PLINDER：切分与泄漏检查通过。
- [ ] MOSES/GuacaMol：生成指标基线固定。
- [ ] Davis/KIBA/BioSNAP：冷启动切分报告。

**DoD**：任一训练/评测任务可导出“数据版本 + 切分哈希 + 指标”三件套，且能重跑得到相同数字。

### 7.3 P2 —— 扩展与增强

- [ ] PubChem 按 assay 抽取，不做全库。
- [ ] DrugBank 在授权范围内接入。
- [ ] Open Targets / PHAROS 证据层。
- [ ] SAIR、USPTO、GDB 子集、FoldBench、COValid。
- [ ] ToxRefDB / EPA CompTox 毒性补充。

**DoD**：新增来源不改变既有标准层语义，只追加证据与关联。

## 8. 反面清单：看起来该做但不该做的事

| 做法 | 为什么不能做 |
|---|---|
| 把所有活性值取平均成一条 | 丢失实验条件与离散度，无法复现，掩盖冲突 |
| 按活性阈值删除“弱活性” | 引入选择偏差，模型评测虚高 |
| 全量导入 PubChem / GDB-17 / ZINC 3D | 存储与查询成本失控，且大多与当前任务无关 |
| 用名称或基因名合并靶点 | 同名不同源、同源不同名都会造成错并 |
| 用单一分辨率阈值删除结构 | 结构适用性是多维的，删除会破坏历史可追溯性 |
| 重新随机切分后与官方榜单比较 | 指标不可比，属于评测口径造假 |
| 把 decoy 当实验阴性 | 破坏监督信号含义 |
| 把 AlphaFold 结构当实验结构展示 | 误导用户与下游对接/基线判断 |
| 用中文名/人工分类覆盖上游字段 | 破坏来源证据，且无法追溯 |
